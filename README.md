# Sinteria Automatizaciones

Sitio existente: https://sinteria.github.io/ — repositorio Sinteria/sinteria.github.io.

Tres páginas comerciales independientes: Inicio, Sistema personalizado y Página web personalizada. Incluye 404, verificación de Google y el logotipo original.

La actualización visual incorpora los siete afiches del paquete del titular, adaptados para retirar bordes de captura, corregir contactos y eliminar la tarifa antigua, junto con 45 imágenes conceptuales (43 creadas en la corrección de repeticiones). Cada una de las 52 imágenes de contenido se utiliza una sola vez en las tres páginas; las variantes responsive y la ampliación representan la misma ubicación. El logotipo y el icono de WhatsApp son elementos comunes de navegación. Las portadas, tarjetas, galerías, proceso, preguntas frecuentes y contacto incluyen imágenes. La galería permite ampliar, avanzar y retroceder; funciona con teclado y conserva el foco al cerrar. Los enlaces a las imágenes también funcionan sin JavaScript.

Animaciones de entrada, profundidad al mover el puntero, tarjetas flotantes y efectos al pasar el cursor. Se respeta el movimiento reducido del sistema y hay una opción para pausar las animaciones.

## SEO de servicios · 26 de octubre de 2026

La web conserva las tres páginas comerciales y su diseño. Se refuerzan títulos, descripciones, encabezados y enlaces; se añaden páginas específicas de inventarios, Apps Script, compras y préstamos/pagos. Los SVG de estas páginas explican flujos y no representan pantallas ni trabajos de clientes. No se modifican las 52 imágenes existentes ni se publican políticas pendientes.

Cada página comercial tiene URL canónica propia, metadatos sociales, datos estructurados de Organization/WebSite/WebPage/Service y ruta de navegación cuando corresponde. Se conserva la verificación de Google y el correo público existente. sitemap.xml enumera las siete páginas; 404 y verificaciones quedan fuera. Los nombres alternativos de marca se declaran en Organization y WebSite, sin saturar el contenido. No se añaden valoraciones, direcciones físicas, precios, certificaciones ni casos de éxito no confirmados.

Los textos comerciales se sirven en HTML y los enlaces funcionan sin JavaScript. seo.css incluye la adaptación de las páginas de servicios y respeta el movimiento reducido ya existente. No se requieren compilación, cookies ni analítica. La publicación de cambios y la solicitud de indexación son procesos diferentes; ningún cambio garantiza indexación ni posiciones.

Google Search Console mantuvo un error de lectura para la ruta histórica /sitemap.xml después del reenvío. Se publica además /sitemap.txt, un formato de mapa admitido por Google, con las mismas siete URL canónicas y referencia adicional en robots.txt. El XML se conserva.
